# Recording interactions

Native recordings save `interactions.json` and include a validated `interactions` track in `project.json`. Version 1 records `click`, `typing`, `selection`, `scroll` and `drag` events on the screen video's source clock. Coordinates and rectangles are normalized to the captured screen/window, with a top-left origin. Each event has an ID, source start/end, position, and optional count, button and geometry provenance.

The Swift helper uses a passive event tap for pointer/key activity and a utility queue for accessibility geometry. Selection checks run at roughly 7 Hz; AX messaging has a 50 ms timeout. Frame capture and the 120 Hz cursor sampler do not wait for individual accessibility requests. Nearby keystrokes form typing bursts; scrolling and selection updates are coalesced. Event storage is capped at 200,000 records and reports truncation explicitly.

Tracking begins with capture and ends when capture finalizes. Events are scoped to source bounds and the selected window/app where applicable. Open Record Studio's own processes and secure text fields are excluded. Accessibility and Input Monitoring are required before recording. Use **Enable required access** in the recording dialog to request macOS approval. The UI and main process check access before allocating a recording, and the native helper and main process verify the typing/selection listener at startup. Tracking always stays on. **Advanced → Automatic zooms** controls only zoom generation, independently for typing, text selection, clicks, scrolling and dragging. Typing and selection default on; clicks, scrolling and dragging default off. Camera, microphone, system audio and zoom preferences persist across launches. Selection/caret geometry depends on the source app's accessibility implementation. Chromium/Electron accessibility trees are activated on first focus. Zero-sized/offscreen caret rectangles fall back to the focused control or a visible parent, even when the pointer is on a different display; fallback events use `position: "element"`. Text selections with a valid range but no range bounds are also retained. Content-free diagnostic counts report observed key events and missing focus/geometry. Finalization reconciles native click events with clean cursor samples regardless of the reported click capability. Missing press edges are recovered with `origin: "cursor"`; existing clicks are matched once within 120 ms to avoid duplicates. Missing typing or selection metadata in older recordings cannot be reconstructed from the cursor.

Only timing, geometry, event types and counts are saved. Key codes are used transiently to ignore shortcuts/navigation; characters, selected text and clipboard contents are never read or stored. Mouse drags and scrolls are available to MCP but do not automatically trigger zooms.

## Zoom creation

Finalizing a new recording groups only the interaction kinds enabled in the recording’s snapshotted auto-zoom preferences. Disabled kinds are still tracked and available to MCP. Text focus takes priority within a group. Sections begin up to 0.6 seconds before activity and remain through a short hold, bounded by the next target and the recording duration. Scale adjusts for selection size, avoids zooming into very broad selections, and uses the existing smooth 0.6-second easing. The existing limit of 80 zoom sections applies. Pointer-only groups follow clean cursor data; text groups use a fixed focus. Each generated section is an ordinary edit and supports adjustment, deletion, undo, saving, previews and rendering. Reopening or changing cuts does not regenerate deleted sections.

## MCP

`get_project` includes interaction coverage and per-type counts. `get_interactions` filters by type, time and source/output timebase; pages up to 1000 events. The response includes project revision and both durations. Passing `expected_revision` keeps pagination consistent across concurrent edits. Source timestamps remain stable; output starts and burst ranges are recalculated through retained cuts and speed. Older cursor projects can expose derived click events. Imported media has no interaction history.

## Validation

- `tests/interactions.test.mjs`: empty/partial native click recovery, fast double clicks, deduplication, idempotence, metadata whitelist, invalid values, burst/time mappings, automatic grouping/focus/bounds, pagination and real MCP persistence/revision conflicts.
- `tests/ui/interactions.spec.mjs`: generated capture protocol through recording UI, auto zooms, edits/delete/undo, saving/cold reopen, MCP cuts/speed/timestamps, preview and decoded render. This does not substitute for native event capture.
- `tests/ui/interaction-access.spec.mjs`: denied access, permission changes before Start, IPC enforcement, listener startup failure, and empty native metadata recovered into saved zooms and MCP timestamps.
- `scripts/check-interactions.mjs`: opt-in generated native text window; actual ScreenCaptureKit capture plus injected click/key events and AppKit selection changes. It checks permission coverage, grouped typing, cursor motion sampling and generated zoom validity, then fully decodes the recording. The check stops input injection if its fixture loses focus and closes only its own fixture window. No webcam or microphone is used.

Evidence files `evidence/interactions/checks.json`, `access-checks.json` and `native.json` identify the exact package/helper tested. Long recordings, physical keyboard drivers and every third-party application's accessibility behavior remain outside these short checks.

Exports include the complete validated interaction track in `export.json`, including disabled zoom triggers and events removed by cuts. `timebase: "source"`, `sourceDuration`, the retained `edits.segments` and playback speed describe the mapping. Recorded text and key contents are never included.

Typing events include `contextRect` for accessible text fields. Automatic text zooms fit the union of the field and the burst’s caret bounds with a safety margin, reducing magnification or retaining the wide shot when necessary. Source coordinates are converted to the editor’s crop-travel coordinates so text near the edges is not clipped.
